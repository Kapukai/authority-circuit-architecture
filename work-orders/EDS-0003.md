# EDS-0003 — Decision Replay Explorer

**Status:** Working Draft 0.1  
**Priority:** Critical path  
**Integration rule:** Isolated product addition; no modification of ACA, KAPU, or existing standards behavior.

## Purpose

Make deterministic replay visible to a human reviewer by comparing an original Decision Proof Record with a replayed record and identifying exact equivalence, changed values, added paths, and removed paths.

## Scope

Included:

- local JSON loading;
- canonical SHA-256 hashing;
- recursive path comparison;
- added, removed, and changed classifications;
- replay summary and comparison export;
- synthetic examples;
- responsive browser interface;
- tests, verification, documentation, and release package.

Excluded:

- legal conclusions;
- identity verification;
- production authentication;
- remote storage;
- automatic alteration of source records;
- human authorization;
- derived authority.

## Acceptance criteria

1. Equivalent records show `REPLAY EQUIVALENT`.
2. Any changed, added, or removed path shows `REPLAY DIVERGENT`.
3. Original and replay hashes are visible.
4. The interface never silently rewrites either source record.
5. A machine-readable comparison artifact can be exported.
6. The package runs without third-party dependencies.
7. Automated verification and tests pass.

## Safety statement

Replay equivalence is not truth, lawful authority, human authorization, or faithful execution. It proves only the comparison result produced from the supplied records.
