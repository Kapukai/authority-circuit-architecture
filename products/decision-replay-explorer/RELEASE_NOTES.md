# EDS-0003 v0.1.0 — Working Draft

Initial isolated product package.

## Added

- browser-based original/replay DPR comparison;
- deterministic canonical hashing;
- changed, added, and removed path visibility;
- replay status and decision-circuit snapshot;
- comparison export;
- synthetic equivalent and divergent examples;
- unit test and package verification;
- capability plan, work order, ADR, and threat model.

## Known limitations

This is a local demonstrator, not a production system. It does not include authentication,
signatures, schema validation, semantic rule equivalence, regulated-data controls, or derived
authority.
