# ADR-0001 — Standalone, dependency-free replay explorer

## Status

Accepted for Working Draft 0.1.

## Context

Replay is currently easy to reduce to a pass/fail label. Reviewers need to observe what was
recomputed and what changed without trusting a server or proprietary UI.

## Decision

Implement the first explorer as static HTML, CSS, and JavaScript using browser-native APIs.

## Consequences

Positive:

- easy local use;
- minimal supply-chain surface;
- no build step;
- transparent comparison logic;
- simple packaging.

Limitations:

- no production identity or access control;
- browser cryptography availability is required;
- large records may require later streaming or indexing;
- schema-specific semantic equivalence is future work.
