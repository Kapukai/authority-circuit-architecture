# Public Disclosure Boundary

This implementation is limited to transparent, table-driven interpretation of
fields already represented by the public Decision Proof Record schema and
canonical working-draft ACA identifiers.

It excludes unpublished Authority Cell runtime mechanics, authority derivation,
graph projections, source extraction, confidence algorithms, replay
orchestration, signing, transparency logs, autonomous agents, and real-case
adjudication. Public release remains subject to human intellectual-property and
licensing review. The repository license does not grant a patent license.
