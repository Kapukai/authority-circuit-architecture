# Governance

## Mission

The Authority Circuit Architecture (ACA) is maintained as an open technical standard for operationalizing transparent, verifiable, accountable public decision systems.

## Principles

- Decisions should be observable.
- Authority should be verifiable.
- Remedy should be operational.
- Standards should be openly published.
- Implementations should remain interoperable.
- Anyone may build compatible implementations.

## Decision Making

Major changes are proposed through Issues and Pull Requests.

The project aims for rough consensus supported by reproducible evidence.

## Standards Process

New standards progress through:

Working Draft

Public Review

Candidate Standard

Stable Standard

Reference implementations should accompany standards whenever practical.

## Licensing

Standards remain openly published.

Implementations may be open or commercial provided compatibility with the published standard is maintained.
