# Standards Program Roadmap

## Phase 0 - Foundation
- Freeze naming and scope.
- Establish repository, versioning, licensing, and contribution rules.
- Publish ACA-000 and ACA-100 as Working Draft 0.1.

## Phase 1 - Formal Core
- Define typed predicates and decision states.
- Define deterministic evaluation order.
- Define Decision Proof Record schema.
- Define remedy lifecycle and closure criteria.

## Phase 2 - Reference Implementation
- Implement one bounded decision profile.
- Produce identical outputs from repeated runs.
- Publish fixtures, expected outputs, and negative tests.

## Phase 3 - Independent Reproduction
- Recruit two independent implementers.
- Compare outputs and document divergence.
- Amend the specification where ambiguity remains.

## Phase 4 - Pilot and Assurance
- Run a narrow voluntary pilot.
- Measure reproducibility, latency, error detection, correction time, and audit cost.
- Publish an independent evaluation.

## Phase 5 - Adoption
- Develop procurement language.
- Develop conformance profiles.
- Seek academic, standards, civic-technology, audit, and public-sector review.
