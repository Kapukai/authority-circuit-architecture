# Standards Program Roadmap

## Phase 0 — Foundation

- Freeze initial naming and scope.
- Establish repository, versioning, licensing, governance, and contribution rules.
- Publish the initial architecture as Working Draft 0.1.

## Phase 1 — Formal Core

- Define typed predicates.
- Define decision states and their formal semantics.
- Define deterministic evaluation order.
- Define state-transition rules.
- Define the Decision Proof Record schema.
- Define remedy triggers, execution states, and closure criteria.
- Publish the ACA conformance specification.

## Phase 2 — Reference Implementation

- Implement one bounded decision profile.
- Publish versioned rules and evidence fixtures.
- Produce deterministic outputs across repeated runs.
- Generate schema-valid Decision Proof Records.
- Add negative, contradiction, replay, tamper, and regression tests.
- Publish expected outputs and reproduction instructions.

## Phase 3 — Independent Reproduction

- Recruit independent implementers.
- Require implementation from the public specification rather than copied code.
- Compare material outputs across implementations.
- Document divergences.
- Amend the specification where ambiguity remains.

## Phase 4 — Public Demonstration

- Publish an interactive demonstrator.
- Expose predicates, evidence provenance, decision state, and remedy route.
- Permit downloadable and replayable Decision Proof Records.
- Publish conformance status and known limitations.

## Phase 5 — Pilot and Assurance

- Run a narrow, voluntary pilot.
- Measure reproducibility, latency, consistency, error detection, correction time,
  audit effort, and implementation cost.
- Obtain independent technical, security, legal, and human-impact review.
- Publish results, limitations, and corrective revisions.

## Phase 6 — Stable Standard

- Resolve material specification ambiguity.
- Publish stable schemas and test vectors.
- Establish a documented release and deprecation policy.
- Publish conformance profiles.

## Phase 7 — Adoption

- Develop procurement language.
- Develop implementation and migration guidance.
- Support academic, engineering, civic-technology, audit, and public-sector review.
- Establish training and independent conformance assessment.

## Phase 8 — Certification

- Define transparent certification criteria.
- Separate open implementation rights from official certification marks.
- Establish renewal, suspension, appeal, and revocation procedures.
