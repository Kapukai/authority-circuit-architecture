# Agent Boundary

## Permitted agent actions

- read the canonical registry and source documents;
- identify gaps, duplicates, dependencies, conflicts, and missing evidence;
- draft an identifier-free proposal;
- execute an authorized work package in an isolated branch;
- generate candidate documentation, schemas, fixtures, and tests;
- report verification results and uncertainty.

## Prohibited agent actions

- assign, reserve, reuse, renumber, or retire an ACA identifier;
- alter canonical registry state without an explicit human-authorized allocation;
- represent a proposal as accepted, released, published, or legally authoritative;
- suppress counter-authority, failed tests, conflicts, or uncertainty;
- merge, publish, deploy, or authorize consequential action.

## Required handoff

Every candidate handoff identifies its work package, source branch, changed
files, tests, unresolved findings, and the human decision still required.
