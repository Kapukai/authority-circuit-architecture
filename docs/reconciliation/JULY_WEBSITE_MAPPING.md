# July 2026 Website Reconciliation

## Purpose

This record distinguishes the generic ACA standards site from the predecessor
Status Integrity Record application recovered from
`website-before-ex010-20260706-172258.tar.gz`.

The archive is preserved as predecessor implementation material. It is not the
canonical source for ACA terminology, requirements, schemas, or publication
status.

## Authority order

1. The version-controlled ACA working draft governs standards terminology,
   identifiers, states, schemas, and publication status.
2. Recovered conversation material may justify reviewed changes but does not
   silently override the repository.
3. The July website contributes reusable interaction and information-design
   patterns.
4. The clean Operationalized Remedy Protocol package is a candidate bounded
   reference implementation pending explicit mapping and review.
5. Deployed server files are release artifacts and never the source of truth.
